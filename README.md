# Action Timer

Dalamud API 15 / .NET 10 向けプラグインです。

## 実装した機能

- 戦闘ジョブを日本語のリストボックスで選択。
- ジョブに対応したPvEアビリティ（ロールアクションを含む）と固有リキャストのウェポンスキルを日本語で一覧表示・検索。
- アビリティごとのチェックボックスで表示を切替。
- 現在のジョブで有効にしたアビリティのアイコンを表示。
- アイコンごとにドラッグ移動、X/Y座標入力、16～256pxのサイズ設定。
- 設定はジョブ・アクションID単位で自動保存。言語設定にかかわらず日本語データを使用。
- クールタイム中は残り秒数、チャージ式は次の補充までの秒数と現在の保有数を表示。
- 準備完了時もアイコンを表示。編集モードを解除するとアイコンはマウス操作を透過。

## v1.4.1 の変更

- 共通設定の「プレビュー・20秒テストラン」に「プレビューアイコンサイズ」を追加しました。16～256px、初期値128pxです。
- 待機時・テスト中・完了後に変更でき、テスト中の変更でカウントダウンはリセットされません。
- サイズは自動保存されます。プレビュー専用で、実際に配置したアイコンのサイズには影響しません。
- 文字サイズは共通設定の値をそのまま使います。アイコンが小さい場合の文字のはみ出しも、実表示と同様にアイコン範囲で切り取ります。
- API 15参照のReleaseビルド成功（警告0・エラー0）。ゲーム内表示は未検証です。

## v1.4.0 の変更

- グラデーション方式を共通設定に移動しました。「時計回り／上から／なし」をすべてのジョブ・アイコンに適用します。個別設定からは削除しました。
- 旧版の個別グラデーション設定は引き継がず、共通設定の初期値「上から」になります。配置・サイズ・文字・枠線の設定は保持します。
- チャージが1以上残っている場合は、従来どおりグラデーションを表示しません。
- 共通設定のプレビューに「20秒テスト開始」を追加。ゲーム内アクションを実行せず、通常の20秒リキャストを再現します。
- テスト中は残り秒数と共通グラデーションを実表示と同じ描画処理で表示し、完了後は数字が消え、元のアイコン色に戻ります。枠線は維持します。
- テスト中の設定変更は即時反映。「20秒テストを再開始」で20秒からやり直し、「リセット」で文字設定用の静止プレビューに戻ります。
- プレビューには設定画面で選択中のジョブの最初の有効アクションを使います。有効なものがなければ一覧の先頭を使用します。テストはアクション本来のリキャストにかかわらず20秒固定です。
- テストは1回で終了します。ウィンドウを閉じている間も時間は経過します。
- Releaseビルド（警告0・エラー0）、20秒タイマーの開始・中間・終了・再開始、グラデーション計算・チャージ条件のテストに成功。ゲーム内描画は未検証です。

## v1.3.0 の変更

- リキャスト秒数・チャージ数をゲーム内蔵の「Miedinger Mid」フォントに変更しました。共通設定画面のプレビューにも反映します。日本語の設定項目は通常フォントのままです。
- 既存の文字サイズ・色・縁取り設定は引き継ぎます。外部フォントのインストールは不要です。
- チャージ式は保有数が1以上ならグラデーションを表示せず、元のアイコン色で表示します。残り0のときだけ、選択したグラデーションを表示します。
- チャージ補充までの秒数と保有数は、チャージが残っていても引き続き表示します。
- Releaseビルド（警告0・エラー0）と、保有数0／1／複数でのグラデーション表示条件テストに成功しました。ゲーム内の描画・フォントの見た目は未検証です。

## v1.2.0 の共通設定

`/actiontimer` の「共通設定を開く」ボタン、または `/actiontimer style` で別ウィンドウを開きます。

- リキャスト秒数とチャージ数それぞれに、文字サイズ・文字色・縁取りの有効／無効・縁取り色・縁取りの太さを設定できます。
- アイコン枠線の有効／無効・色・太さも共通設定で変更できます。通常表示・配置編集どちらにも適用されます。
- すべてのジョブ・アイコンに即時適用し、自動保存します。個別の文字設定はありません。
- 共通設定画面には文字と枠線のプレビューを表示します。
- 表示対象・配置・アイコンサイズ・グラデーション方式は既存設定を保持します。
- 旧版の個別文字設定は共通設定に統合するため引き継ぎません。初回はリキャスト白20px、チャージ黄16px、文字の縁取り黒1px、アイコン枠線黄1pxになります。
- API 15参照でビルド成功（警告0・エラー0）。ゲーム内の見た目・保存と再ロードは未検証です。

## v1.1.0 の追加機能（文字設定はv1.2.0で共通化）

- 固有リキャストのウェポンスキルを追加。回転のこぎりはゲーム上ではウェポンスキルに分類されるため、従来のアビリティ限定条件では除外されていました。
- 共通設定で、リキャスト秒数とチャージ数それぞれの文字サイズ（8～96px）・色（透明度含む）を変更できます。
- アイコンごとにグラデーションを「時計回り」「上から」「なし」から選択できます。初期値は「上から」です。
- リキャスト開始時は暗い表示になり、経過に応じて元のアイコン色が現れます。「時計回り」は12時方向から、「上から」は上端から復元します。「なし」はアイコンの元の色を常時表示します。
- チャージ式の進捗は次の1チャージ補充までを1周とします。全チャージ回復時は完全に元の色へ戻ります。
- 既存の選択・配置設定は引き継ぎ、新しい項目には初期値を使用します。

## 更新方法

プラグインをアンロードしてからDLLとJSONを新しいものに置き換え、再ロードしてください。プラグイン設定ファイルの削除は不要です。

## 導入

1. Dalamud API 15を導入した環境を用意します。
2. 同梱のビルド済み `bin/Release/ActionTimer.dll` と `ActionTimer.json` を同じ場所に置きます。
3. Dalamudの開発用プラグイン設定に `ActionTimer.dll` の絶対パスを登録します。
4. プラグインインストーラーの開発用プラグインから Action Timer をロードします。
5. チャット欄で `/actiontimer` を実行します。

開発用プラグイン設定の項目名はDalamudの表示言語によって異なります。通常は `/xlsettings` の Experimental 内にある Dev Plugin Locations を使用します。

## 操作

1. 左側でジョブを選択します。
2. 表示したいアビリティにチェックを入れます。
3. X/Yとサイズを指定します。座標原点はゲーム画面左上です。
4. マウスで移動する場合は、そのジョブに着替えて「配置編集」を有効にし、アイコンをドラッグします。
5. 編集後は「配置編集」を解除します。`/actiontimer edit` でも切り替えられます。

設定画面は別ジョブも編集できますが、画面上のアイコンは現在のジョブだけ表示します。
画面外の座標を入力した場合、表示位置は画面内へ補正されます。

## 対象範囲と注意点

- 対象はゲームデータ上の「アビリティ」と固有リキャストのウェポンスキルです。回転のこぎり、ドリル等を含み、通常のGCDのみのウェポンスキル・魔法・PvP専用アクション・クラフター／ギャザラーは対象外です。
- 未習得レベルのアビリティも設定できるよう一覧に含めています。表示は使用可能判定を意味しません。
- アイコンとリキャストの取得にはゲームの置き換え後アクションIDを使用します。上位アクションと下位アクションを両方選択すると表示が重複する場合があります。
- 非ログイン時はアイコンを表示しません。配置編集モードは起動時に無効になります。
- この環境ではAPI 15の実DLLを参照してReleaseビルドを確認済みです（警告0、エラー0）。ゲーム内でのロード・描画・実際のリキャスト計測は未検証です。

## ビルド

必要条件：.NET 10 SDK、Dalamud API 15開発用アセンブリ。

```powershell
dotnet build ActionTimer.csproj -c Release
```

Dalamud.NET.Sdk/15.0.0 を使用します。通常は `%APPDATA%/XIVLauncher/addon/Hooks/dev` を参照します。
出力は `bin/Release/ActionTimer.dll`、マニフェストは `bin/Release/ActionTimer.json` です。

## ゲーム内の確認項目

- 設定画面でジョブ名・アビリティ名が日本語になり、対象ジョブのロールアクションが出ること。
- チェック切替で表示が変わり、ジョブ変更時に表示が入れ替わること。
- 通常アビリティ使用後に残り秒数が減少し、完了時に数字が消えること。
- チャージ式を1回／連続で使い、保有数と次の補充までの秒数がゲームのホットバーと一致すること。
- レベルシンク、上位置き換え、共有リキャスト、エリア移動後の挙動。
- ドラッグと座標入力、サイズ変更、再ロード後の保存状態。
- 回転のこぎりが一覧に含まれ、通常のGCDウェポンスキルが含まれないこと。
- リキャスト／チャージの文字サイズ・色をそれぞれ変更し、再ロード後も保持されること。
- 3種類のグラデーションを切り替え、通常リキャストとチャージ式の進捗が一致すること。
- 編集解除後にアイコンの下にあるゲームUIをクリックできること。
