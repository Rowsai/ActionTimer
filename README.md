# Action Timer

Dalamud API 15 / .NET 10 向けプラグインです。

## 実装した機能

- 戦闘ジョブを日本語のリストボックスで選択。
- ジョブに対応したPvEアビリティ（ロールアクションを含む）と固有リキャストのウェポンスキルを日本語で一覧表示・検索。
- アビリティごとのチェックボックスで表示を切替。
- 現在のジョブで有効にしたアビリティのアイコンを表示。
- アイコンごとにドラッグ移動、X/Y座標入力、16～256pxのサイズ設定。
- 設定はジョブ・アクションID単位で自動保存。言語設定にかかわらず日本語データを使用。
- クールタイム中は残り秒数、チャージ式は次の補充までの秒数と現在の保有数を表示。
- 準備完了時もアイコンを表示。編集モードを解除するとアイコンはマウス操作を透過。
